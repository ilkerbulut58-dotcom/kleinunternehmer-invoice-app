# Kleinunternehmer Invoice App

Diese Anwendung ist ein Rechnungs- und Verwaltungssystem für Kleinunternehmer gemäß §19 UStG (Kleinunternehmerregelung) in Deutschland.

Sie richtet sich an Selbstständige und Freelancer, die einfache, gesetzeskonforme Rechnungen erstellen und ihre Einnahmen übersichtlich verwalten möchten.

---

## 🚀 Funktionen

- 🧾 Erstellung von Rechnungen als PDF  
- 🇩🇪 Automatischer Hinweis gemäß §19 UStG (keine Ausweisung der Umsatzsteuer)  
- 👤 Kundenverwaltung  
- 🔢 Automatische Rechnungsnummerierung  
- 📊 Übersicht und Verwaltung der Einnahmen  
- 💾 Speicherung der Daten in einer Datenbank (lokal oder serverbasiert)  

---

## 🛠 Technologie

- PHP  
- MySQL oder SQLite  
- HTML / CSS  
- PDF-Generator  

---

## ⚙️ Installation (Kurzfassung)

1. Projektdateien auf einen Webserver hochladen  
2. Datenbank einrichten oder konfigurieren  
3. Konfigurationsdatei anpassen  
4. Anwendung im Browser aufrufen und verwenden
